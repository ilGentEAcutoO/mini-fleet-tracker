# Mini Fleet Tracker

A fleet management demo built with Go (Fiber), Vue 3 (Nuxt 3), and the Cloudflare ecosystem (D1, KV, R2, Durable Objects, Workers, Containers).

> ⚠️ Work in progress. Live demo at https://fleet-tracker.jairuchan.com runs **until 2026-05-31**. After that, see the source in this repo.
